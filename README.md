# MMOS — Mask Lighting Studio

A lightweight browser-based photo lighting workspace inspired by the five-mask workflow in the supplied reference.

## Features
- Upload JPEG, PNG, or WebP photographs.
- Five editable mask groups: Model, Background, Linear Gradient, Rimlight, and Sunlight.
- Independent controls for Exposure, Contrast, Saturation, and Temperature where relevant.
- Before/after wipe preview.
- Export a new high-quality JPEG; the source file is not overwritten.
- Runs locally in the browser without uploading photographs to a server.

## Important implementation note
This first build uses Canvas overlays and spatial gradients. It does **not** perform semantic subject segmentation, automatic background selection, true edge-aware rim-light masking, or Lightroom-grade RAW processing. "Model" adjustments currently approximate global tonal lift; "Background" approximates edge darkening. It never claims to identify or edit faces independently. A later phase can add a segmentation model and region-specific pixel processing.

## Run
No build tools or dependencies are required. Open `index.html` in a modern browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080

## Deploy with GitHub Pages
A GitHub Actions workflow is included at `.github/workflows/pages.yml`.
1. Open repository **Settings → Pages**.
2. Under **Build and deployment → Source**, select **GitHub Actions**.
3. Open the **Actions** tab and check the workflow named "Deploy MMOS Mask Lighting Studio to GitHub Pages".
4. When the run finishes successfully, open **Settings → Pages** to see the published website URL.
5. Every new commit to `main` triggers a new deployment.

## Roadmap
- Real subject/background segmentation and editable mask refinement.
- Per-mask HSL and color temperature via pixel color transforms.
- Brush / erase tools and mask feathering.
- Side-by-side and draggable comparison modes.
- Lightroom-compatible preset export (XMP); DNG camera profiles are a separate format and are not generated by this web editor.
